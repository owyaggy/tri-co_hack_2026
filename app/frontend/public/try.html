Try Dialectic

A class reads together: highlight a passage, ask about it, and your classmates answer first. AI only steps in as far as the class charter allows.

On the web (any device)

Open Dialectic
  1. Click Start the demo. The server sleeps when nobody's using it, so the first page can take a few seconds.
  2. Pick a student (try Ana). No passwords; the professor's side is password-protected on this public copy.
  3. Open Week 1 · Hobbes. Select a sentence, then Ask or Note.
  4. Highlights in the margin are the class's notes. Table shows who wrote where.

iPhone and iPad

Open the web link above in Safari, then Share → Add to Home Screen for a full-screen app.

The native app (Apple Pencil highlighting, Ask from any app) is in TestFlight; a public install link is waiting on Apple's beta review. On iPad with the app: drag the Pencil across a line like a highlighter, lift, and Ask | Note opens. Fingers scroll.

Mac app

The Mac app (ask about a passage from any app with ⌃ ⌥ D) works with a copy of Dialectic running on your own Mac, not with this public copy. How to set it up is in the project's README.
